# 📊 Zomato Dataset (Raw Data)

This folder contains the **raw datasets** used for building the Zomato Data Analytics Dashboard project.

---

## 📁 Folder Contents

The dataset includes files related to:

- 🧾 Orders data  
- 👥 Users data  
- 🌍 City / Area data  
- 🍲 Food category data  
- ⭐ Ratings data  

---

## ⚠️ Important Note

- This is **raw and unprocessed data**
- Data may contain:
  - Missing values
  - Duplicates
  - Inconsistent formats
- Data cleaning and preprocessing are required before analysis
