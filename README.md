# 🍽️ Zomato Data Analytics Dashboard

A visually rich and interactive **Data Analytics Dashboard** inspired by Zomato, built to analyze food delivery trends, user behavior, and sales performance across different cities and demographics.

---

# 📌 Project Overview

This project presents a **multi-page analytical dashboard** designed to provide deep insights into:

* 📊 Sales performance
* 👥 User demographics
* 🌍 Area-wise distribution
* 🍲 Category-based food trends

The dashboard is designed with a **modern UI/UX layout**, focusing on clarity, storytelling, and business insights.

---

# 🎯 Objectives

* Analyze **sales trends over time**
* Identify **top-performing cities and regions**
* Understand **user behavior by age and gender**
* Compare **food category preferences (Veg / Non-Veg / Others)**
* Provide **business-ready insights** for decision making

---
