# 📌 Project Overview

🚀 This project transforms raw Zomato-style data into **interactive business insights** using a modern and visually appealing dashboard design.

It focuses on:
- 📊 Sales Performance  
- 👥 User Behavior  
- 🌍 Area-wise Analysis  
- 🍲 Food Category Trends
